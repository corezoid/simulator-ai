# Layer statistics

`graph_layer_stats_get(actorId)` maps the named legacy `layerStats` capability to
public `graph/layer/stats/get`. It is available in `graph-read` and `graph-create`,
requires `actors.readonly` and current layer View, and injects the host workspace.
Optional `SIMULATOR_AI_ACTOR` with `graph-read` binds the layer: only this tool is
exposed, accepts `{}`, and rejects every supplied actor/workspace argument. This
mode neither accepts delegated tokens nor exposes graph writes or unrelated reads.

All six integer fields are required: `nodes`, `edges`, `holes`, `holesClosed`,
`edgeHoles`, `edgeHolesClosed`. Zero is preserved; missing/null/negative/fractional
counters fail the whole read. Extra backend fields are not projected. No error is
converted into a zero result and the client does not cache or retry reads.

Counts are placements, including repeated nodes, eligible virtual containment
edges and geometry-only placements allowed by the current layer policy. Recipient
restrictions check original roots and actual hole/edge references; API users do
not inherit human recipients. The server repairs missing shared Scylla counters
as documented, but these are not response authority: a primary aggregation runs
for the current viewer, including with warm shared counters. A policy/database
failure has no shared-cache fallback. Repair and projection have the server's
15-second deadline, are not one snapshot, and do not publish a realtime frame.

```json
{"name":"graph_layer_stats_get","arguments":{"actorId":"LAYER_ACTOR_ID"}}
```

This is a read capability with legacy-compatible maintenance of shared counters,
not a model-directed graph mutation. Counts cannot certify complete pagination,
absence of private rows or exact receipt readback. Use `graph_elements_get` for
known placement IDs. The portable graph skill distinguishes these workflows.

Current recipient privacy checks apply even when shared counters are already cached.
The source contract is `contracts/layer-stats-openrpc.json`, generated by
`cmd/gen-graph-contract -profile layer-stats` from a reviewed public snapshot.
See [live authorization checks](live-backend-acceptance.md) for the backend verification boundary.
